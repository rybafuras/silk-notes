# Changelog

## 1.3.0

- Added Settings with English, Polish, German, and Romanian.
- Added custom colors with contrast validation, default fonts/sizes, and spell-check.
- Moved appearance and autosave controls into Settings.
- Added Markdown source editing, preview, saving, autosave, and recovery.
- Added folder browsing, child-folder creation, and selected-folder save defaults.
- Set the app author and installer publisher to rybcia.
- Added localized-window screenshots and regression tests for new features.

## 1.2.0

- Added System, Light, and Dark appearance without changing saved RTF colors.
- Added note tabs with individual undo and crash recovery.
- Added find/replace, case and whole-word options, and replace-all undo.
- Added opt-in autosave with external file-change detection.
- Added focus mode and keyboard shortcuts.
- Added a self-contained per-user installer, upgrades, shortcuts, and uninstall.
- Expanded regression coverage and included refreshed screenshots.

## 1.1.0

- Replaced the standard title bar with custom controls and native Windows drag/resize integration.
- Added an owned, themed save confirmation with explicit action labels.
- Kept edits safe when cancelling, closing the prompt, or encountering a save failure.
- Replaced the app logo and executable icon with the supplied shark artwork.
- Extracted window design, theme, startup, and tests into separate source files.
- Added explanatory comments, an MIT license, build/test scripts, and contributor documentation.

## 1.0.0

- Initial rich-text editor, local fonts, images, RTF persistence, recent files, and recovery.
